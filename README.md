# Roastify AI

Build a modern AI SaaS web tool called "Cartory Roastify AI".

Purpose:

Cartory Roastify AI is an intelligent website analysis tool that “roasts” websites by identifying weaknesses and providing actionable suggestions to improve design, SEO, speed, and conversion performance.

Target Users:

- Small business owners

- Freelancers

- Marketing agencies

- Startup founders

Core Rules:

- No login or signup required

- Instant analysis

- Beginner-friendly

- Mobile responsive

- Fast loading

- Clean, modern UI

Main User Flow:

Step 1:

User pastes a website URL.

Step 2:

User clicks "Roast My Website".

Step 3:

AI analyzes the website.

Step 4:

User receives a detailed report with scores and suggestions.

---

Core Features:

1. AI Website Analyzer

Analyze the following:

• Design Quality

• Mobile Responsiveness

• Page Speed (simulated)

• SEO Structure

• Content Clarity

• Conversion Optimization (CTA, layout)

---

2. Smart Scoring System

Display scores (0–100):

• Design Score

• SEO Score

• Speed Score

• Conversion Score

Show scores visually using:

- Progress bars

- Circular indicators

---

3. AI Roast Report (Main Feature)

Provide brutally honest but helpful feedback.

Example:

❌ Weak headline — does not clearly explain the offer  

❌ No strong call-to-action  

❌ Poor mobile layout  

❌ Slow loading impression  

---

4. AI Fix Suggestions

For each problem, provide solutions:

Example:

Problem:

Weak headline

Fix:

"Rewrite your headline to clearly explain what you offer and who it's for."

---

5. Quick Improvement Tips

Show 5–10 quick wins:

• Add CTA button above the fold  

• Improve loading speed  

• Use customer testimonials  

---

6. Copy & Export

User can:

• Copy full report  

• Download report (PDF style layout)
